## Description

Proxy Manager is a fast proxy switcher for Chrome. Save your HTTP, HTTPS, SOCKS4 and SOCKS5 proxies once, then turn any of them on or off with one click right from the toolbar. Proxies with a username and password work too: the extension signs in for you, so Chrome never asks for proxy credentials.

Bring your own proxies. Proxy Manager does not sell or include proxy servers. It is a clean, private control panel for the proxies you already use: from a residential or datacenter proxy provider, your company network or your own server.

⚡ Switch proxies in one click
• Every saved proxy is one click away in the popup. Click a card or flip its switch to connect, click again to go direct.
• The power button turns the proxy off without losing your selection.
• The toolbar icon shows the flag or icon of the connected proxy, so you always know which exit you are using.

🔐 HTTP, HTTPS and SOCKS5 proxy with authentication
• Supports HTTP, HTTPS, SOCKS4 and SOCKS5 proxy servers.
• Username and password authentication for HTTP and HTTPS proxies, answered automatically with no login prompts.
• Paste a proxy in any common format and the form fills itself: host:port, host:port:user:pass, user:pass@host:port or socks5://user:pass@host:port.

✅ Built-in proxy checker
• Test a proxy before you save it. Proxy Manager opens a test connection through it and shows the exit IP address, country and latency.
• Saving runs the check automatically, so a dead proxy or a wrong password never ends up in your list. You can still save anyway when you know better.
• Clear messages instead of cryptic error codes: rejected credentials, unreachable host, refused tunnel, timeout.

🌍 Flags and icons for every proxy
• Give each proxy a country flag (every country is available) or one of ten icons for work, home, gaming, streaming and more.
• One click applies the flag of the country the proxy check detected.

🧭 Bypass list
• Keep localhost, your intranet and any domain you choose off the proxy.
• Wildcards like *.example.com and the <local> rule for plain host names are supported.

🛡️ Private by design
• Open source: the code is public, so you can check exactly what the extension does.
• No account, no sign up, no ads, no analytics, no tracking.
• Your proxies and passwords are stored only in the extension's local storage in your browser and are never sent to the developer.
• Proxy Manager contacts the network on its own only through your proxy: one sign-in request when you connect to a proxy with a password, and the proxy checks you start, which ask Cloudflare, Amazon AWS, ipinfo.io and ipify for the exit IP address.
• A half-filled form is remembered, so switching windows never loses your input.

❓ FAQ

Is this a VPN?
No. Proxy Manager sets the proxy for Chrome only. Other apps on your computer keep their usual connection, and the extension does not come with proxy servers of its own.

Does SOCKS5 support a username and password?
Chrome does not support authentication for SOCKS proxies, so SOCKS4 and SOCKS5 proxies need to be authorized by IP address. HTTP and HTTPS proxies support a username and password.

Does it work alongside other proxy extensions?
Chrome lets only one extension control the proxy at a time. If another extension takes over, Proxy Manager tells you so and explains how to fix it.
