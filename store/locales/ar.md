# Chrome Web Store listing — العربية

## Name

Proxy Manager: إدارة بروكسي HTTP وHTTPS وSOCKS5

## Summary

بدّل البروكسي بنقرة واحدة. احفظ بيانات الدخول واختبر الاتصال وحدد الاستثناءات. بلا حساب أو إعلانات.

## Category

Privacy & Security

## Language

العربية

## Description

يحفظ Proxy Manager خوادم البروكسي HTTP وHTTPS وSOCKS4 وSOCKS5 الخاصة بك ويتيح التبديل بينها بنقرة من شريط أدوات Chrome. استخدم خوادمك الخاصة: الإضافة لا توفر خوادم بروكسي ولا تبيعها وليست VPN. تغيّر بروكسي Chrome فقط، وتحتفظ التطبيقات الأخرى باتصالها المعتاد.

التبديل والإعداد
فعّل البروكسي أو أوقفه من بطاقته. يحتفظ زر التشغيل الرئيسي باختيارك عند قطع الاتصال. عيّن أسماء وأعلام أي دولة أو عشر أيقونات متاحة. تعرض أيقونة الشريط البروكسي المتصل. تُحفظ مسودة النموذج عند التبديل بين النوافذ.

المصادقة والاستثناءات
مصادقة تلقائية باسم المستخدم وكلمة المرور لبروكسي HTTP وHTTPS. لا يدعم Chrome مصادقة SOCKS؛ لذا اسمح بعنوان IP الخاص بك لدى المزود لاستخدام SOCKS4 وSOCKS5. الصق host:port أو host:port:user:pass أو user:pass@host:port أو عنوان URL كاملاً لملء النموذج. استثنِ localhost والشبكة الداخلية والنطاقات بقواعد مثل *.example.com و<local>.

فحص الاتصال
اختبر البروكسي قبل الحفظ واعرض عنوان IP الخارجي والدولة وزمن الاستجابة. يجري الفحص عند الحفظ إذا لزم الأمر، ويمكن الحفظ حتى عند فشل الاختبار. تشرح الرسائل أخطاء بيانات الدخول والخادم والنفق وانتهاء المهلة. يُفحص الاتصال النشط عند التفعيل وبعد إعادة تشغيل المتصفح أو العملية الخلفية وكل دقيقة وبعد بعض الأخطاء وعند الطلب. تستخدم الفحوص Cloudflare وAmazon AWS وipinfo.io وipify.

الخصوصية والتحكم
شفرة مفتوحة المصدر. بلا حساب أو تسجيل أو إعلانات أو تحليلات أو تتبع. تُخزّن إعدادات البروكسي وكلمات المرور محلياً في المتصفح ولا تُرسل إلى المطور. تُرسل بيانات الدخول فقط إلى البروكسي المعني عندما يطلب المصادقة. يسمح Chrome لإضافة واحدة فقط بالتحكم في البروكسي؛ وعند التعارض تختار الإضافة المنافسة التي تريد تعطيلها.

للتطوير واختبار الصفحات حسب المنطقة وتحسين محركات البحث والفرق التي تستخدم عدة خوادم بروكسي.

واجهة الإضافة باللغة الإنجليزية. الترجمة خاصة بصفحة المتجر فقط.
