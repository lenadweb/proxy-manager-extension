## Name

Proxy Manager: gestor de proxies HTTP, HTTPS y SOCKS5

## Summary

Cambia de proxy con un clic. Guarda credenciales, comprueba conexiones y configura excepciones. Sin cuenta ni anuncios.

## Category

Privacy & Security

## Language

Español

## Description

Proxy Manager permite guardar tus proxies HTTP, HTTPS, SOCKS4 y SOCKS5 y cambiar entre ellos desde la barra de Chrome con un clic. Usa tus propios servidores: la extensión no incluye ni vende proxies y no es una VPN. Solo cambia el proxy de Chrome; las demás aplicaciones conservan su conexión habitual.

CAMBIO Y CONFIGURACIÓN
Activa o desactiva un proxy desde su tarjeta. El botón de encendido conserva la selección al desconectar. Asigna nombres, banderas de cualquier país o uno de diez iconos; el icono de la barra muestra el proxy conectado. Los borradores del formulario se guardan al cambiar de ventana.

AUTENTICACIÓN Y EXCEPCIONES
Autenticación automática con usuario y contraseña para HTTP y HTTPS. Chrome no admite autenticación SOCKS: para SOCKS4 y SOCKS5, autoriza tu dirección IP en el proveedor. Pega host:port, host:port:user:pass, user:pass@host:port o una URL completa para rellenar el formulario. Excluye localhost, tu intranet o dominios con reglas como *.example.com y <local>.

COMPROBACIÓN DE CONEXIÓN
Comprueba un proxy antes de guardarlo y consulta la IP de salida, el país y la latencia. Al guardar se ejecuta una comprobación si hace falta; puedes guardar aunque falle. Los errores explican problemas de credenciales, servidor, túnel o tiempo de espera. La conexión activa se verifica al activar el proxy, tras reinicios del navegador o del proceso en segundo plano, cada minuto, tras ciertos errores y a petición. Las comprobaciones utilizan Cloudflare, Amazon AWS, ipinfo.io e ipify.

PRIVACIDAD Y CONTROL
Código abierto. Sin cuenta, registro, anuncios, analítica ni seguimiento. Proxies y contraseñas se guardan localmente en el navegador y no se envían al desarrollador. Las credenciales solo se envían al proxy correspondiente cuando solicita autenticación. Chrome permite que una sola extensión controle el proxy; si hay un conflicto, puedes elegir qué extensión competidora desactivar.

Para desarrollo, pruebas de páginas por región, SEO y equipos que usan distintos proxies.
