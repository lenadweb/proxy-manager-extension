# Chrome Web Store listing — Bahasa Indonesia

## Name

Proxy Manager: pengelola proxy HTTP, HTTPS dan SOCKS5

## Summary

Ganti proxy dengan sekali klik. Simpan kredensial, uji koneksi, dan atur pengecualian. Tanpa akun atau iklan.

## Category

Privacy & Security

## Language

Bahasa Indonesia

## Description

Proxy Manager menyimpan proxy HTTP, HTTPS, SOCKS4, dan SOCKS5 Anda agar dapat beralih dengan sekali klik dari bilah alat Chrome. Gunakan server sendiri: ekstensi ini tidak menyediakan atau menjual proxy dan bukan VPN. Hanya proxy Chrome yang berubah; aplikasi lain tetap menggunakan koneksi biasanya.

BERALIH DAN MENGATUR
Aktifkan atau nonaktifkan proxy dari kartunya. Tombol daya utama mempertahankan pilihan saat koneksi diputus. Beri nama, bendera negara mana pun, atau satu dari sepuluh ikon. Ikon bilah alat menunjukkan proxy yang terhubung. Draf formulir tetap tersimpan saat berpindah jendela.

AUTENTIKASI DAN PENGECUALIAN
Autentikasi otomatis dengan nama pengguna dan kata sandi untuk HTTP dan HTTPS. Chrome tidak mendukung autentikasi SOCKS: untuk SOCKS4 dan SOCKS5, izinkan alamat IP Anda di penyedia. Tempel host:port, host:port:user:pass, user:pass@host:port, atau URL lengkap untuk mengisi formulir. Lewati proxy untuk localhost, intranet, dan domain dengan aturan seperti *.example.com dan <local>.

PEMERIKSAAN KONEKSI
Uji sebelum menyimpan dan lihat IP keluar, negara, serta latensi. Penyimpanan menjalankan pemeriksaan jika perlu; Anda tetap dapat menyimpan meski pengujian gagal. Pesan yang jelas menjelaskan kesalahan kredensial, server, tunnel, dan waktu habis. Koneksi aktif diperiksa saat diaktifkan, setelah browser atau proses latar belakang dimulai ulang, setiap menit, setelah kesalahan tertentu, dan atas permintaan. Pemeriksaan menggunakan Cloudflare, Amazon AWS, ipinfo.io, dan ipify.

PRIVASI DAN KONTROL
Kode sumber terbuka. Tanpa akun, pendaftaran, iklan, analitik, atau pelacakan. Proxy dan kata sandi disimpan secara lokal di browser dan tidak dikirim ke pengembang. Kredensial hanya dikirim ke proxy terkait saat meminta autentikasi. Chrome hanya mengizinkan satu ekstensi mengontrol proxy; jika terjadi konflik, Anda memilih ekstensi pesaing yang akan dinonaktifkan.

Untuk pengembangan, pengujian halaman menurut wilayah, SEO, dan tim yang memakai beberapa proxy.

Antarmuka ekstensi berbahasa Inggris. Hanya halaman toko yang diterjemahkan.
