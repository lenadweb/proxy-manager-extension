# Chrome Web Store listing — 日本語

## Name

Proxy Manager: HTTP・HTTPS・SOCKS5プロキシ管理

## Summary

ワンクリックでプロキシを切り替え。認証情報の保存、接続テスト、除外ルールの設定に対応。アカウント不要、広告なし。

## Category

Privacy & Security

## Language

日本語

## Description

Proxy Managerは、お持ちのHTTP・HTTPS・SOCKS4・SOCKS5プロキシを保存し、Chromeのツールバーからワンクリックで切り替える拡張機能です。プロキシサーバーの提供や販売は行いません。VPNではなく、Chromeのプロキシ設定のみを変更します。他のアプリは通常の接続を維持します。

切り替えと設定
カードからプロキシを有効・無効にできます。メインの電源ボタンで無効にしても選択は保持されます。名前、すべての国の国旗、10種類のアイコンを設定可能。ツールバーのアイコンで接続中のプロキシを確認できます。ウィンドウを切り替えても入力途中のフォームは保存されます。

認証と除外ルール
HTTP・HTTPSではユーザー名とパスワードによる自動認証に対応。ChromeはSOCKS認証に対応していないため、SOCKS4・SOCKS5はプロバイダー側でIPアドレスを許可してください。host:port、host:port:user:pass、user:pass@host:port、または完全なURLを貼り付けてフォームに入力できます。*.example.comや<local>などのルールで、localhost、イントラネット、指定ドメインをプロキシの対象から除外できます。

接続チェック
保存前にテストして、出口IPアドレス、国、遅延を確認できます。保存時は必要に応じてチェックを実行し、失敗しても保存できます。認証情報、サーバー、トンネル、タイムアウトのエラーを分かりやすく表示。接続は有効化時、ブラウザーやバックグラウンド処理の再起動後、毎分、一部のエラー発生後、および手動操作時にチェックします。チェックにはCloudflare、Amazon AWS、ipinfo.io、ipifyを利用します。

プライバシーと制御
オープンソース。アカウント登録、広告、利用分析、追跡はありません。プロキシとパスワードはブラウザー内にローカル保存され、開発者には送信されません。認証情報は、該当するプロキシが認証を要求した場合にのみ送信されます。Chromeでは同時に1つの拡張機能だけがプロキシを制御できます。競合時は、無効にする他の拡張機能を自分で選べます。

開発、地域別のページ検証、SEO、複数のプロキシを使うチームに。

拡張機能の操作画面は英語です。翻訳されているのはストアの掲載情報のみです。
