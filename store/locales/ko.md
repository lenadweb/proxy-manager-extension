## Name

Proxy Manager: HTTP, HTTPS, SOCKS5 프록시 관리

## Summary

클릭 한 번으로 프록시를 전환하세요. 로그인 정보 저장, 연결 테스트, 예외 규칙 설정을 지원합니다. 계정과 광고가 없습니다.

## Category

Privacy & Security

## Language

한국어

## Description

Proxy Manager는 HTTP, HTTPS, SOCKS4, SOCKS5 프록시를 저장하고 Chrome 도구 모음에서 클릭 한 번으로 전환하는 확장 프로그램입니다. 직접 준비한 서버를 사용하세요. 프록시 서버를 제공하거나 판매하지 않으며 VPN이 아닙니다. Chrome의 프록시만 변경하므로 다른 앱은 기존 연결을 유지합니다.

전환과 설정
프록시 카드에서 연결을 켜고 끄세요. 기본 전원 버튼으로 꺼도 선택은 유지됩니다. 이름, 모든 국가의 국기 또는 10가지 아이콘 중 하나를 지정할 수 있습니다. 도구 모음 아이콘은 연결된 프록시를 표시합니다. 창을 전환해도 작성 중인 양식은 보존됩니다.

인증과 예외
HTTP와 HTTPS는 사용자 이름과 비밀번호로 자동 인증합니다. Chrome은 SOCKS 인증을 지원하지 않으므로 SOCKS4와 SOCKS5는 제공업체에서 IP 주소를 허용해야 합니다. host:port, host:port:user:pass, user:pass@host:port 또는 전체 URL을 붙여 넣어 양식을 채우세요. *.example.com과 <local> 같은 규칙으로 localhost, 인트라넷, 특정 도메인을 프록시에서 제외할 수 있습니다.

연결 확인
저장 전에 테스트하여 외부 IP 주소, 국가, 지연 시간을 확인하세요. 저장 시 필요하면 검사하며, 실패해도 저장할 수 있습니다. 인증 정보, 서버, 터널, 시간 초과 오류를 알기 쉽게 표시합니다. 활성 연결은 켤 때, 브라우저나 백그라운드 프로세스가 다시 시작된 후, 매분, 일부 오류 발생 후, 사용자 요청 시 검사됩니다. 검사에는 Cloudflare, Amazon AWS, ipinfo.io, ipify를 사용합니다.

개인정보 보호와 제어
오픈 소스입니다. 계정, 가입, 광고, 사용 분석, 추적이 없습니다. 프록시와 비밀번호는 브라우저에 로컬로 저장되며 개발자에게 전송되지 않습니다. 인증 정보는 해당 프록시가 인증을 요청할 때만 전송됩니다. Chrome에서는 한 번에 하나의 확장 프로그램만 프록시를 제어할 수 있습니다. 충돌 시 비활성화할 다른 확장 프로그램을 직접 선택하세요.

개발, 지역별 페이지 테스트, SEO, 여러 프록시를 사용하는 팀에 적합합니다.

확장 프로그램의 인터페이스는 영어입니다. 스토어 등록 정보만 번역되었습니다.
