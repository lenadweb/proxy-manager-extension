# Chrome Web Store listing — Polski

## Name

Proxy Manager: zarządzaj proxy HTTP, HTTPS i SOCKS5

## Summary

Zmieniaj proxy jednym kliknięciem. Zapisuj dane logowania, testuj połączenia i ustawiaj wyjątki. Bez konta i reklam.

## Category

Privacy & Security

## Language

Polski

## Description

Proxy Manager zapisuje serwery proxy HTTP, HTTPS, SOCKS4 i SOCKS5 i pozwala przełączać je jednym kliknięciem z paska Chrome. Korzystaj z własnych serwerów: rozszerzenie nie dostarcza ani nie sprzedaje proxy i nie jest VPN-em. Zmienia proxy tylko w Chrome; inne aplikacje zachowują zwykłe połączenie.

PRZEŁĄCZANIE I KONFIGURACJA
Włączaj i wyłączaj proxy z jego karty. Główny przycisk zachowuje wybór po rozłączeniu. Dodawaj nazwy, flagi dowolnych krajów lub jedną z dziesięciu ikon. Ikona na pasku pokazuje połączone proxy. Wpisy w formularzu pozostają zapisane przy zmianie okna.

UWIERZYTELNIANIE I WYJĄTKI
Automatyczne logowanie nazwą użytkownika i hasłem dla HTTP i HTTPS. Chrome nie obsługuje uwierzytelniania SOCKS: dla SOCKS4 i SOCKS5 autoryzuj swój adres IP u dostawcy. Wklej host:port, host:port:user:pass, user:pass@host:port lub pełny URL, aby wypełnić formularz. Pomijaj proxy dla localhost, intranetu i domen za pomocą *.example.com i <local>.

SPRAWDZANIE POŁĄCZENIA
Testuj proxy przed zapisem i sprawdzaj wyjściowy adres IP, kraj i opóźnienie. Zapis uruchamia test w razie potrzeby; możesz zapisać mimo niepowodzenia. Czytelne komunikaty wyjaśniają błędy logowania, serwera, tunelu i limitu czasu. Aktywne połączenie jest sprawdzane przy włączeniu, po ponownym uruchomieniu przeglądarki lub procesu w tle, co minutę, po niektórych błędach i na żądanie. Testy korzystają z Cloudflare, Amazon AWS, ipinfo.io i ipify.

PRYWATNOŚĆ I KONTROLA
Otwarty kod. Bez konta, rejestracji, reklam, analityki i śledzenia. Proxy i hasła są przechowywane lokalnie w przeglądarce i nie trafiają do twórcy. Dane logowania są wysyłane tylko do właściwego proxy, gdy poprosi o uwierzytelnienie. Chrome pozwala tylko jednemu rozszerzeniu sterować proxy; przy konflikcie wybierasz, które konkurencyjne rozszerzenie wyłączyć.

Dla programistów, testerów stron regionalnych, specjalistów SEO i zespołów korzystających z wielu proxy.

Interfejs jest po angielsku. Przetłumaczono tylko stronę w sklepie.
