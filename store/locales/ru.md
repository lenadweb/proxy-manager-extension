## Category

Privacy & Security

## Language

Русский

## Description

Proxy Manager сохраняет ваши HTTP-, HTTPS-, SOCKS4- и SOCKS5-прокси и позволяет переключаться между ними в один клик с панели Chrome. Используйте свои серверы: расширение не предоставляет и не продаёт прокси и не является VPN. Оно меняет прокси только для Chrome; остальные приложения используют обычное подключение.

ПЕРЕКЛЮЧЕНИЕ И НАСТРОЙКА
Включайте и отключайте прокси через его карточку. Общий выключатель сохраняет выбор после отключения. Задавайте имена, флаги любых стран или одну из десяти иконок. Значок на панели показывает подключённый прокси. Черновик формы сохраняется при переключении окон.

АВТОРИЗАЦИЯ И ИСКЛЮЧЕНИЯ
Автоматическая авторизация по логину и паролю для HTTP и HTTPS. Chrome не поддерживает авторизацию SOCKS: для SOCKS4 и SOCKS5 разрешите свой IP у провайдера. Вставьте host:port, host:port:user:pass, user:pass@host:port или полный URL для заполнения формы. Исключайте localhost, интранет и домены с помощью правил *.example.com и <local>.

ПРОВЕРКА СОЕДИНЕНИЯ
Проверяйте прокси перед сохранением: расширение покажет выходной IP, страну и задержку. При сохранении проверка запускается при необходимости; сохранить можно и при ошибке. Понятные сообщения объясняют проблемы с паролем, сервером, туннелем и временем ожидания. Активное соединение проверяется при включении, после перезапуска браузера или фонового процесса, каждую минуту, после некоторых ошибок и по запросу. Для проверок используются Cloudflare, Amazon AWS, ipinfo.io и ipify.

КОНФИДЕНЦИАЛЬНОСТЬ И КОНТРОЛЬ
Открытый исходный код. Без аккаунта, регистрации, рекламы, аналитики и отслеживания. Прокси и пароли хранятся локально в браузере и не отправляются разработчику. Учётные данные передаются только соответствующему прокси по его запросу авторизации. Chrome разрешает управлять прокси только одному расширению; при конфликте вы сами выбираете, какое конкурирующее расширение отключить.

Для разработки, проверки страниц в разных регионах, SEO и команд, использующих несколько прокси.

Интерфейс расширения — на английском. Переведена только страница в магазине.
