# Chrome Web Store listing — ไทย

## Name

Proxy Manager: จัดการพร็อกซี HTTP, HTTPS และ SOCKS5

## Summary

สลับพร็อกซีในคลิกเดียว บันทึกข้อมูลเข้าสู่ระบบ ทดสอบการเชื่อมต่อ และตั้งข้อยกเว้น ไม่ต้องมีบัญชี ไม่มีโฆษณา

## Category

Privacy & Security

## Language

ไทย

## Description

Proxy Manager บันทึกพร็อกซี HTTP, HTTPS, SOCKS4 และ SOCKS5 ของคุณเพื่อสลับจากแถบเครื่องมือ Chrome ในคลิกเดียว ใช้เซิร์ฟเวอร์ของคุณเอง ส่วนขยายนี้ไม่ได้ให้บริการหรือขายพร็อกซี และไม่ใช่ VPN โดยจะเปลี่ยนพร็อกซีของ Chrome เท่านั้น แอปอื่นยังใช้การเชื่อมต่อตามปกติ

การสลับและตั้งค่า
เปิดหรือปิดพร็อกซีจากการ์ด ปุ่มเปิดปิดหลักจะเก็บตัวเลือกเดิมไว้เมื่อตัดการเชื่อมต่อ ตั้งชื่อ เลือกธงของประเทศใดก็ได้ หรือเลือกหนึ่งในสิบไอคอน ไอคอนบนแถบเครื่องมือแสดงพร็อกซีที่เชื่อมต่ออยู่ แบบร่างของฟอร์มจะยังอยู่เมื่อสลับหน้าต่าง

การยืนยันตัวตนและข้อยกเว้น
ยืนยันตัวตนอัตโนมัติด้วยชื่อผู้ใช้และรหัสผ่านสำหรับ HTTP และ HTTPS โดย Chrome ไม่รองรับการยืนยันตัวตน SOCKS สำหรับ SOCKS4 และ SOCKS5 ให้อนุญาตที่อยู่ IP ของคุณกับผู้ให้บริการ วาง host:port, host:port:user:pass, user:pass@host:port หรือ URL แบบเต็มเพื่อกรอกฟอร์ม ยกเว้น localhost เครือข่ายภายใน และโดเมนจากพร็อกซีด้วยกฎ เช่น *.example.com และ <local>

ตรวจสอบการเชื่อมต่อ
ทดสอบก่อนบันทึกและดู IP ขาออก ประเทศ และความหน่วง ระบบจะตรวจสอบเมื่อบันทึกหากจำเป็น และยังบันทึกได้แม้ทดสอบไม่ผ่าน ข้อความที่ชัดเจนอธิบายข้อผิดพลาดของข้อมูลเข้าสู่ระบบ เซิร์ฟเวอร์ ทันเนล และการหมดเวลา ตรวจสอบการเชื่อมต่อที่ใช้งานเมื่อเปิด หลังรีสตาร์ตเบราว์เซอร์หรือกระบวนการเบื้องหลัง ทุกนาที หลังข้อผิดพลาดบางประเภท และเมื่อสั่งตรวจสอบ โดยใช้ Cloudflare, Amazon AWS, ipinfo.io และ ipify

ความเป็นส่วนตัวและการควบคุม
โอเพนซอร์ส ไม่ต้องมีบัญชีหรือสมัครสมาชิก ไม่มีโฆษณา การวิเคราะห์การใช้งาน หรือการติดตาม พร็อกซีและรหัสผ่านเก็บไว้ในเบราว์เซอร์บนอุปกรณ์และไม่ส่งให้นักพัฒนา ข้อมูลเข้าสู่ระบบส่งให้พร็อกซีที่ตรงกันเท่านั้นเมื่อร้องขอการยืนยันตัวตน Chrome อนุญาตให้ส่วนขยายเดียวควบคุมพร็อกซีในแต่ละครั้ง หากขัดแย้งกัน คุณเลือกได้ว่าจะปิดส่วนขยายอื่นใด

สำหรับการพัฒนา การทดสอบหน้าเว็บตามภูมิภาค SEO และทีมที่ใช้หลายพร็อกซี
