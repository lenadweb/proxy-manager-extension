# Chrome Web Store listing — 简体中文

## Name

Proxy Manager：HTTP、HTTPS 和 SOCKS5 代理管理器

## Summary

一键切换代理，保存登录信息，测试连接并设置绕过规则。无需账号，没有广告。

## Category

Privacy & Security

## Language

简体中文

## Description

Proxy Manager 可保存您的 HTTP、HTTPS、SOCKS4 和 SOCKS5 代理，并从 Chrome 工具栏一键切换。请使用您自己的服务器：本扩展不提供或出售代理服务器，也不是 VPN。它仅更改 Chrome 的代理设置，其他应用仍使用原有连接。

切换与配置
通过代理卡片开启或关闭连接。主开关关闭代理后仍保留选择。为代理设置名称、任意国家的旗帜或十种图标之一。工具栏图标显示当前连接的代理。切换窗口时，尚未填写完成的表单会保留。

认证与绕过规则
HTTP 和 HTTPS 支持用户名和密码自动认证。Chrome 不支持 SOCKS 认证，因此 SOCKS4 和 SOCKS5 需要在服务商处授权您的 IP 地址。粘贴 host:port、host:port:user:pass、user:pass@host:port 或完整 URL 即可填写表单。使用 *.example.com 和 <local> 等规则，让 localhost、内网和指定域名绕过代理。

连接检查
保存前测试代理，查看出口 IP、国家和延迟。保存时会按需检查，即使测试失败也可以保存。清晰的提示说明凭据、服务器、隧道和超时错误。启用代理后、浏览器或后台进程重启后、每分钟、部分错误发生后以及手动请求时，都会检查当前连接。检查使用 Cloudflare、Amazon AWS、ipinfo.io 和 ipify。

隐私与控制
开源代码。无需账号或注册，无广告、使用分析或跟踪。代理和密码仅保存在浏览器的本地存储中，不会发送给开发者。只有对应代理请求认证时，才会向其发送登录信息。Chrome 同时只允许一个扩展控制代理；发生冲突时，您可以自行选择禁用哪个其他扩展。

适用于开发、按地区测试页面、SEO，以及使用多个代理的团队。

扩展界面为英语。仅商店页面已翻译。
