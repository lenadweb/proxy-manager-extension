# Chrome Web Store listing — 繁體中文

## Name

Proxy Manager：HTTP、HTTPS 與 SOCKS5 代理伺服器管理

## Summary

一鍵切換代理伺服器，儲存登入資訊、測試連線並設定略過規則。免帳號、無廣告。

## Category

Privacy & Security

## Language

繁體中文

## Description

Proxy Manager 可儲存您的 HTTP、HTTPS、SOCKS4 與 SOCKS5 代理伺服器，並從 Chrome 工具列一鍵切換。請使用自己的伺服器：本擴充功能不提供或販售代理伺服器，也不是 VPN。它只變更 Chrome 的代理設定，其他應用程式仍使用原有連線。

切換與設定
透過代理卡片開啟或關閉連線。主開關關閉後仍會保留選擇。為代理設定名稱、任意國家的國旗或十種圖示之一。工具列圖示會顯示目前連線的代理。切換視窗時，尚未填完的表單會保留。

驗證與略過規則
HTTP 與 HTTPS 支援以使用者名稱和密碼自動驗證。Chrome 不支援 SOCKS 驗證，因此 SOCKS4 與 SOCKS5 需要在服務供應商處授權您的 IP 位址。貼上 host:port、host:port:user:pass、user:pass@host:port 或完整 URL 即可填入表單。使用 *.example.com 與 <local> 等規則，讓 localhost、內部網路與指定網域略過代理。

連線檢查
儲存前測試代理，查看出口 IP、國家與延遲。儲存時會視需要檢查，即使測試失敗也能儲存。清楚的訊息說明登入資訊、伺服器、通道與逾時錯誤。啟用代理後、瀏覽器或背景程序重新啟動後、每分鐘、部分錯誤發生後，以及手動要求時，都會檢查目前連線。檢查使用 Cloudflare、Amazon AWS、ipinfo.io 與 ipify。

隱私與控制
開放原始碼。免帳號、免註冊，無廣告、使用分析或追蹤。代理和密碼僅儲存在瀏覽器的本機儲存空間，不會傳送給開發者。只有對應代理要求驗證時，才會傳送登入資訊。Chrome 同時只允許一個擴充功能控制代理；發生衝突時，您可以自行選擇停用哪個其他擴充功能。

適合開發、依地區測試網頁、SEO，以及使用多個代理的團隊。
